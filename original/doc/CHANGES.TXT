
        News in version 1.0.16:

        * Added IMPORT directive (RDF target). Declares external
          symbols supplied at link time; each name becomes a
          RDFREC_IMPORT record with a unique segid starting at 3.
          Imported names are usable in MOV imm16, MOV [mem],
          DW / DD, CALL rel16, JMP rel16, and SEG operand forms
          (RDFREC_RELOC absolute or relative per context). JMP SHORT
          / Jcc / LOOP to an import is rejected (out of range).
        * Added JMP FAR / CALL FAR. Direct form (JMP FAR <symbol>)
          emits EA / 9A + offset16:segment16 with a RDFREC_RELOC
          on the offset slot and a RDFREC_SEGRELOC on the segment
          slot — RDF-only. Indirect form (JMP FAR [mem]) emits
          FF /5 (jmp) or FF /3 (call) and works for any target.
          Register operands and numeric operands are rejected.
        * Instruction matcher tightened: user-written SHORT / NEAR /
          FAR is now a hard constraint. Previously a table entry
          with LEX_NONE would silently absorb any user-specified
          lex2, so e.g. JMP FAR <r16> fell through to the near
          FF /4 form. Now unsupported forms produce "Syntax error".

        News in version 1.0.15:

        Code review pass (later in the same cycle):
        * decdigit() now correctly uses `&&` (was `||`, accepted any
          char as a decimal digit).
        * get_const() now reports division/modulo by zero instead of
          letting the host CPU raise SIGFPE.
        * `END` without an argument is accepted (just stops parsing).
        * Per-line memset of t_line replaced with field-by-field reset;
          ~8KB shaved per source line.
        * SEG operator now errors out cleanly for non-RDF targets
          (bin/com/texe) instead of silently treating SEGfoo as an
          undefined constant.
        * is_reg() now returns int with -1 as the not-found sentinel;
          -funsigned-char workaround dropped from MAKEGNU.MAK.
        * Collapsed the nine OP_CMD_RM*/RMLINE_* arms in
          do_instruction() into a single do_rm_op() helper.
        * Deduped reloc emission helpers (rseg_for_section /
          reloc_if_symbol).
        * Removed dead externs and unused locals; fixed all
          -Wunused-variable warnings; eliminated stray // C++ comments.
        * Renamed all build/test files to DOS 8.3 (Makefile.gnu →
          MAKEGNU.MAK, test_*.c → T_*.C, test_runner.c → RUNNER.C,
          test.h → TEST.H).
        * Removed .ovl target.
        * Added -f rdf target: RDOFF2 (NASM "rdf") relocatable object
          file with RDFREC_RELOC and RDFREC_SEGRELOC records,
          RDFREC_GLOBAL for EXPORT-marked labels, and RDFREC_BSS for
          .bss reservation.
        * Added SECTION / SEGMENT directive (.text / .data / .bss) and
          RESB / RESW / RESD reservation pseudo-ops.
        * Added the SEG unary operator: "mov ax, seg label" and
          "dw seg label" produce RDFREC_SEGRELOC records.
        * Added MAKEGNU.MAK for POSIX / GCC builds; existing MAKEFILE
          remains Watcom/DOS only.
        * Added in-process C89 unit tests under original/tests/.
          Run with: make -f MAKEGNU.MAK test (from original/src/).
